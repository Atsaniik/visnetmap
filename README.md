# visnetmap

`visnetmap` provides simple Python tools for generating interactive network and map visualizations as standalone HTML files.

## Features

- Interactive network graph using vis-network
- Interactive geographical network map using Leaflet
- Support for NetworkX-like graphs
- Node and edge hover tooltips
- HTML export
- Optional browser opening
- Optional geocoding with geopy/Nominatim

## Installation

```bash
pip install visnetmap
